# portefolio-final

Portfolio professionnel de **Jocelyn Hermann** — Développeur Full Stack basé à Fianarantsoa, Madagascar.

🔗 Démo locale : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python3 -m http.server 8080
```

## Contenu

- `index.html` — page unique (Accueil, À propos, Compétences, Expérience, Projets, Formation, Contact)
- `assets/css/style.css` — styles (thème clair/sombre, responsive)
- `assets/js/main.js` — interactions (menu, filtres projets, animations)
- `assets/img/` — photo de profil
- `assets/CV-Jocelyn-Hermann.pdf` — CV téléchargeable

## Stack

HTML / CSS / JavaScript vanilla — aucune dépendance de build.
